Course Telegram Groups

Save a private Telegram group invite link for each course. After you verify a student's UPI payment and approve it, the student will see a Join Telegram Group button in My Courses.

Use a private group with join requests enabled. Students can forward invite links, so approve Telegram join requests separately. A website payment approval does not automatically add anyone to Telegram.
